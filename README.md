## About

This is the source for my personal portfolio: my experience, projects, education, certifications, leadership and skills in one place.

> **Design shows the work. Logic holds it up.**
> I get the data and the logic right first, so the design has something solid to stand on.

## Features

- **Light and dark themes** that follow your device setting, with a toggle to switch anytime
- **Responsive layout** for phones, tablets and desktops
- **Sliding navigation** that highlights the section you're reading
- **Subtle motion**: text that rises in on load, sections that fade in as you scroll, and a dot grid that lights up around your cursor
- **Accessible**: keyboard focus styles, and animations turn off when your device asks for reduced motion
- **No frameworks, no build step**: plain HTML, CSS and JavaScript

## Project structure


## Run it locally

Open `index.html` in any browser. Nothing to install.

## Updating the site

| To change… | Edit |
| --- | --- |
| Projects or skills | the lists at the top of `js/main.js` |
| Experience, education, certifications, leadership | `index.html` |
| Colors or fonts | the tokens at the top of `css/style.css` |
| Certificate images | add the file to `assets/certs/` and a card in `index.html` |

Then publish:

```bash
git add .
git commit -m "Describe what you changed"
git push
```

GitHub Pages updates the live site within a minute or two.
